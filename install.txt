MC-challenge-HUB - client install guide (Windows)
=================================================

FIRST INSTALL  (MC-challenge-HUB-Client.zip)
1. Start Minecraft Java 26.3 once in the official launcher, then close
   the game AND the launcher.
2. Extract the whole ZIP (do not run it from inside the ZIP).
3. Double-click install.cmd. An internet connection is needed.
4. Open the launcher, choose the profile "MC-challenge-HUB" (ice crystal icon),
   press Play.
5. Multiplayer -> add the server address you got from the server owner.

UPDATE THE SHADER
In game: Esc -> Shader -> Update shader (from version 1.0.9 on). From version 1.0.11 on
the menu updates too without restarting Minecraft. By hand:
(ScopeCrystal-Shader.zip)
1. Close Minecraft and extract the whole ZIP.
2. Double-click update-shader.cmd.
Your shader settings are kept. The Shader Menu mod is updated too. Use /getshader on the server for the latest link.

VR (Quest 3 and other SteamVR headsets)
Double-click install-vr.cmd. It adds a second launcher profile "MC-challenge-HUB VR"
with Vivecraft and its own folder (.minecraft\mc-hub-vr); the normal profile stays as it is.
Start SteamVR first (Quest: Link cable, Air Link or Virtual Desktop), then play the VR profile.
The shader starts with the profile "Performance": VR draws every picture twice.
Updates: Esc -> Shader -> Update shader inside the VR profile.

GOOD TO KNOW
- Fullbright: B turns it on/off (with the shader). Choose "Caves" or "Full" once in
  Esc -> Shader. Without the shader: Gamma Utils, key under Options -> Controls -> Gamma Utils.
- K turns the shader on/off, F9 switches the shader profile.
- Pause menu -> Shader: profile, effects and all settings. Keys can be changed in
  Options -> Controls -> Shader.
- Normal worlds look vanilla; effects only appear in the hub and arena.
- Your old mods folder, shaderpack and Iris settings are saved in
  .minecraft\mc-hub-backup\<date>. Mods from your old mods folder are not
  active anymore until you copy them back.
- Do not copy the shader folder by hand: the installer also builds two
  textures from your own Minecraft.
- Do not update Sodium on its own: Iris 1.11.7 needs Sodium 0.9.2.

WHAT GETS INSTALLED
Fabric Loader 0.20.1, Fabric API 0.166.2, Sodium 0.9.2, Iris 1.11.7, Gamma Utils
3.2.2 (fullbright, needs Cloth Config 26.3.159; all downloaded
from Fabric and Modrinth, checksums verified), the ScopeCrystal shaderpack and
our own small Shader Menu mod (included in the ZIP).

UNDO
Choose your normal launcher profile. To restore old mods, copy them back from
the backup folder.
